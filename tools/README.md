# Сбор комментариев YouTube под сегмент

## Установлено

- `yt-dlp` через Homebrew (`/opt/homebrew/bin/yt-dlp`)
- скрипт `fetch_comments.py` — выгружает и ранжирует комментарии

ffmpeg и Whisper пока не нужны — они понадобятся только для расшифровки аудио.

## Как пользоваться

```bash
cd ~/Documents/layout/regress/tools

# один ролик
python3 fetch_comments.py "https://www.youtube.com/watch?v=XXXX"

# несколько сразу
python3 fetch_comments.py "ссылка1" "ссылка2" "ссылка3"

# ограничить количество (по умолчанию 300)
python3 fetch_comments.py "ссылка" --limit 500
```

Результат: `out/<id>.md` — отчёт с тремя блоками. Сырой JSON остаётся в `data/`.

## Что делает фильтр

**Жёсткий отсев** (в таблицу не попадёт никогда):
- ответы автора канала
- короче 60 знаков
- реклама, ссылки, «спасибо за видео»
- вероятно мужской род — по глаголам на `-л` без `-ла` и по словам «жена», «женитьба», «буду честен»
- возраст вне 28–47, если он назван прямо

**Баллы:**

| Признак | Вес |
|---|---|
| Незакрытость: «не могу», «не знаю», «как избавиться», «непонятно» | +3 за каждый, максимум 9 |
| Тело: сон, тревога, напряжение, зажим, сердце, дышать, боли | +2 за каждый, максимум 8 |
| Маркеры жизни: муж, дети, работа, мама, возраст | +1 за каждый, максимум 3 |
| Женский род найден явно | +2 |
| Длиннее 400 знаков | +2 |
| Короткая, но с телом и незакрытостью | +4 |
| Уже вышла: «мне помогло», «избавилась», «теперь я» | −6 |
| Советует другим | −6 |

Пороги: **Берём** от 6, **Под вопросом** 2–5, ниже — отсев.

## Настройка

Словари в начале `fetch_comments.py`: `UNRESOLVED`, `BODY`, `LIFE`, `RESOLVED`, `NOISE`, `ADVICE`.
Добавляй слова туда по мере того, как будут попадаться новые формулировки.

Скрипт **ранжирует, а не решает**. Блок «Под вопросом» всегда стоит просматривать
глазами — там регулярно лежит что-то стоящее.

## Ограничения

- yt-dlp иногда ломается после обновлений YouTube: `brew upgrade yt-dlp`
- с VPS может прилетать «Sign in to confirm you're not a bot»; с домашнего мака работает
- выгрузка 300 комментариев занимает 1–3 минуты
